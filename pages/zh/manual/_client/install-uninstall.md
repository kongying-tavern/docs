## 配置要求 {#requirements}

运行本地图软件（以下简称「本软件」），需要满足以下软硬件要求：

- 系统：Windows 10 x64 或 Windows 11 x64。
- 硬盘：`C` 盘分区保留 500M 磁盘空间，软件安装所在分区保留 1G 磁盘空间。

以下为其他推荐配置：

- CPU：Intel® Core™ i3 10100 及以上 / AMD Ryzen™ 3 3300X 及以上。
- GPU：NVIDIA GeForce® GTX 1060 及以上 / AMD Radeon™ RX 580 及以上。
- 内存：8G 及以上。
- 显示器：1920 × 1080 及以上分辨率。

## 安装流程 {#install}

- 若已安装《空荧酒馆原神地图》（以下简称「本软件」），则可直接根据[更新流程](#update)步骤进行操作。
  - 若在已安装本软件的前提下，按照安装流程进行安装，则可能会对当前安装的本软件进行覆盖安装，或在当前电脑上留下本软件的多个副本。
  - 若需删除多余的副本，可参照[卸载](#uninstall)操作删除多余的软件副本。
- 根据[下载客户端][link:download-client]中提供的下载方式，下载本软件。
- 软件分为免安装版和安装版两种，根据喜好任选其一即可。安装流程如下：
  - 免安装版为压缩包，仅需使用解压软件解压至非游戏路径即可。使用解压后目录中的 `Map.exe` 文件可启动地图。
  - 安装版为安装向导，根据向导提示操作即可完成安装。安装后会自动生成桌面快捷方式与开始菜单项，可通过快捷方式或菜单项启动地图。

::: tip 提示

推荐使用以下解压工具进行解压：

- [7\-zip][link:7zip]
- [Bandizip][link:bandizip]
  - Bandizip 有免费版与专业版，日常使用仅需使用免费版本即可。免费版存在一些广告，请注意甄别。

:::

## 更新流程 {#update}

::: tip 提示

由于软件架构更新，本软件无法直接从公测版本（Beta 版本）升级为发行候选版本（Rc 版本）。请使用[安装流程](#install)中的方法，使用最新 Rc 版本软件覆盖现有软件。

:::

::Placeholder{hint="【图片】版本更新弹窗：此处应有一个弹窗提示更新的图（建议使用 Rc1.0.0，然后提示更新到 Rc1.0.1）"}

::

- 若已安装本软件，由于本软件目前为发行候选版本，在联网状态下启动本软件，可直接更新至最新版本。
  - 若软件存在版本更新，会弹窗提示版本更新，并在浏览器中打开更新日志。
  - 若软件存在资源热更新，则不会弹窗提示，仅在启动时自动更新。

## 卸载 {#uninstall}

根据本软件安装方式的不同，有不同的卸载方式：

- 若安装时使用的是安装版，可使用以下任意方案进行卸载：
  - Windows 自带方案：使用[添加或删除程序][link:uninstall-windows]对本软件进行卸载。
  - 第三方卸载：可使用第三方带卸载程序功能的软件进行卸载。
- 若安装时使用的是免安装版，直接删除 `Map.exe` 文件所在的目录即可。

## FAQ {#faq}

:::QAGroup
::QA
#question
软件安装路径应该如何选择？

#answer
软件安装路径，根据不同的情况有不同的选择：

- 若使用安装版，且尚未安装本软件，则可选择一个非游戏所在的路径安装。
- 若使用安装版，且已安装本软件，则需使用本软件目前安装路径，实现覆盖安装。
- 若使用免安装版，则仅需解压到一个非游戏所在的路径即可。此操作可能会在电脑上留存本软件的多个副本。

选择安装路径时，需注意以下事项：

- 由于 Unity 框架中存在大量同名但内容可能存在差异的框架文件。为防止框架文件覆盖导致无法启动软件 / 游戏，安装路径不能与《原神》或其他 Unity 架构的软件 / 游戏的安装路径一致。
::

::QA
#question
安装或解压软件后，启动软件时为何提示缺失文件？

#answer
软件中的一些定时检测、下载、上传数据的操作，可能与病毒特征行为类似，从而导致杀毒软件的误杀。请检查杀毒软件拦截列表中是否存在本地图软件的文件，可从杀毒软件中恢复文件，或在设置杀毒软件白名单后重新进行安装或解压。
::

::QA
#question
免安装版的多个副本是否会影响存档数据？

#answer
用户存档独立于软件本体存在，因此多个免安装版副本可共享存档数据。但并不建议在同一台电脑上留存本软件的多个副本。
::

::QA
#question
卸载本软件是否会影响存档数据？

#answer
用户存档与软件的存放位置不同，因此卸载本软件并不影响本机数据。但更换电脑、更换 Windows 账号、重装系统等操作会导致本地数据丢失。可使用 :Placeholder{inline hint="【链接】云存档（待补链接）"} 保存当前的标记进度，以防丢失。
::

::QA
#question
安卓、iOS、Mac 系统是否可以安装本软件？

#answer
当前客户端为 Windows 版本，无法在上述系统中运行。

若需要在其他系统中运行，可使用 :Placeholder{inline hint="【链接】网页版（待补链接）"}。
::

::QA
#question
为什么提示「不受支持的文件格式」？

#answer
运行该软件的设备不支持 `.exe` 格式的文件，请使用搭载 Windows 系统的设备运行本软件。
::

::QA
#question
在线解压后，软件为什么无法运行？

#answer
在线解压功能并未将本软件下载至当前设备上，同时也不存在软件运行所需的环境，因此无法运行软件。请按照[安装与更新](#install)的流程，将免安装版下载至电脑上后，解压并运行。
::

::QA
#question
运行免安装版时，为什么提示缺少文件或「Fatal error」？

#answer
请先检查下载的免安装包是否完整，可尝试重新下载免安装包进行覆盖安装。

请先将免安装包内的文件解压至本地磁盘，再运行本软件。直接在解压软件中启动 `Map.exe`，会导致软件依赖的部分文件无法释放到本地磁盘中，从而影响软件的正常运行。
::
:::
