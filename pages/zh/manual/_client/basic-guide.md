## 启动软件 {#launch}

打开本软件，进入启动界面。在启动界面上单击，即可进入地图界面。

::Placeholder{hint="【图片】启动界面截图。"}

::

## 功能区介绍 {#function-areas}

地图界面中，各功能区域如下：

::Placeholder{hint="【图片】截图保留展开的侧边栏面板，对功能区进行框选标记。"}

::

- 地图区（①）：可交互的地图区域。
- 派蒙面板（②）：含有派蒙头像的左侧面板，可折叠。
  - 物品选择器：派蒙面板中，左下方的面板，用于过滤基础物品分类。
  - 宝箱选择器：派蒙面板中，左上方的面板，是从物品选择器中分离出来，仅用于过滤宝箱物品分类的选择面板。
  - 已选物品列表：已选中的基础物品或宝箱物品的列表，位于派蒙面板右侧。
- 功能按钮区（③）：位于右上角，包含多种功能按钮的区域。具体功能会在后续功能章节进行介绍。
- 操作功能区（④）：位于右侧，用于扩展地图操作功能的区域。
- 快捷开关区（⑤）：位于右下角，方便用户操作的快捷开关区域。

::: tip 提示

该章节后续内容及其他章节中，功能区域名称与此处保持一致，将不再进行赘述。

:::

## 基础使用 {#basics}

### 地图缩放 {#map-zoom}

地图缩放有以下几种方法：

- 使用鼠标滚轮，可缩放地图大小。
- 使用操作功能区右侧的滑动条进行地图缩放：
  - 点击滑动条上方的 :Placeholder{inline hint="【图标】加号图标（Btn_Slider_Plus.png）"} 可放大地图区，点击滑动条下方的 :Placeholder{inline hint="【图标】减号图标（Btn_Slider_Minus.png）"} 可缩小地图区。
  - 拖动滑动条上下移动，可放大或缩小地图区。

### 派蒙面板折叠 {#panel-collapse}

派蒙面板有以下三种状态：

- 展开：派蒙面板将始终保持展开状态。
- 折叠：派蒙面板将始终保持折叠状态。
- 自动展开 / 折叠：当鼠标由地图区移入派蒙面板时，自动展开派蒙面板；鼠标从派蒙面板移出时，折叠派蒙面板。

通过点击派蒙面板右上角的派蒙头像，将按照自动展开 / 折叠 → 折叠 → 展开的顺序循环切换面板状态。

### 点位筛选 {#marker-filter}

::Placeholder{hint="【图片】勾选了部分物品和宝箱获取方式的截图，视图区内保留被筛选出的点位。"}

::

本软件中，筛选点位时的层级顺序依次为：一级地区、二级地区、分类、物品、点位。

其中，

- 一级地区指的是国家，或者某个分类地图（如海岛、琉形蜃境等）。
- 二级地区指的是提瓦特地图内某个特定区域（如龙脊雪山、地下矿区等），或某个活动限时地图（如三界路飨祭等）。
- 分类（全称为【物品分类】），是对物品特性的归类，包含见闻、矿物、敌人等。
- 物品指的是游戏中各种同类调查物（如神瞳、仙灵）的归类。
- 点位为本软件中最小的操作单位，与游戏中的各类可调查物的调查点存在对应关系。

在筛选点位之前，我们需要先选择所需的物品。

#### 基础物品选择 {#select-items}

若要选择所需的物品，操作步骤如下：

- 点击派蒙面板中，派蒙头像下方的地区图标，可展开一级和二级的地区选择。
- 左侧圆形按钮为一级地区按钮，右侧文本按钮为二级地区按钮。
  - 点击二级地区按钮时，物品选择器及宝箱选择器中显示的物品，为当前二级地区的物品。
  - 对于此处按钮的详细操作，参见[地区按钮行为][link:area-button-behavior]。
- 在物品选择器面板中，点击面板上的分类，先切换至所需分类，再在列表中点击需要选择的物品。已选择的物品会显示在已选择物品列表中。
- 在已选择物品列表中，
  - 列表中的条目，会合并显示不同地区的同名物品。
  - 合并显示的物品右下角为物品条数。
  - 点击合并的物品图标，可删除整个合并分组。
  - 将光标移动至合并的物品上，右侧会出现被合并的物品条目。点击右侧条目，可删除对应物品条目的选择。
  - 点击已选择物品列表最上方的 :Placeholder{inline hint="【图标】清空选择物品（Icon_Item_Clear.png）"} 按钮，可清空已选择物品列表。
- 切换二级地区，不影响已选择的物品。

#### 宝箱物品选择 {#select-chests}

由于宝箱的分类与基础物品略有区别，宝箱可同时属于【宝箱品质】与【获取方式】分类，因此本软件将宝箱物品选择面板与基础物品选择面板独立成不同面板。

在具体操作上，宝箱物品的选择大致与基础物品选择类似，仅包含以下区别：

- 选择宝箱物品时，所需面板为宝箱选择器面板。
- 宝箱选择器顶部，存在【宝箱品质】与【获取方式】分类标签页。切换标签页后，宝箱物品列表也会切换至对应分类。
- 分类标签页左侧有【全选】按钮，点击此按钮可切换当前分类的全选 / 取消全选。
- 【全选】按钮会随着当前分类的选中状态改变。
  - 若当前分类中，所有物品均已选中，则全选按钮状态为 :Placeholder{inline hint="【图标】全选状态（Icon_Chest_CheckedAll.png）"}。
  - 若当前分类中，部分物品已选中，则全选按钮状态为 :Placeholder{inline hint="【图标】半选状态（Icon_Chest_CheckedHalf.png）"}。
  - 若当前分类中，无物品选中，则全选按钮的状态为 :Placeholder{inline hint="【图标】未选状态（Icon_Chest_UncheckedAll.png）"}。
- 点击分类标签页右侧的 :small_red_triangle: / :small_red_triangle_down:，可展开 / 折叠宝箱选择器面板。
- 宝箱面板下方，有宝箱成就计数，此计数数量与游戏内成就数计数一致。
- 宝箱选择器面板中，【宝箱品质】与【获取方式】无需同时选择。

### 地区按钮行为 {#area-button-behavior}

一级、二级地区按钮中，不同的操作具有不同的功能。

- 点击二级地区按钮时，会进行以下操作：
  - 地区切换为点击的二级地区。
  - 物品选择器及宝箱选择器中显示的物品，变更为当前二级地区的物品。
  - 地图移动至对应二级地区的区域。
- 点击一级地区按钮时，等价于点击此一级地区中第一个二级地区。
- 右键点击二级地区按钮时，地图会移动至对应二级地区的区域，但不会切换地区、物品选择器和宝箱选择器。

### 点位弹窗 {#marker-popup}

::Placeholder{hint="【图片】包含点位弹窗的截图，要求：点位弹窗内有截图、有视频、倒计时。"}

::

在选择物品后，地图区中将显示属于对应物品的点位。点击点位，将弹出点位弹窗。

点位弹窗中，存在以下内容：

- 点位 ID：位于点位弹窗右下角，该 ID 全地图唯一。
- 标题
- 内容：
  - 当光标在内容区中时，若文本过长，可通过鼠标滚轮，或拖动文本区右侧的滚动条，对内容区进行滚动。
- 图片：
  - 图片用于提供游戏内场景截图，以供用户对比，从而确认点位的具体位置或详细信息。
  - 图片为点位的补充信息，并非所有的点位都有图片。
- 视频
  - 视频用于提供比较完整的点位探索指引，点击点位弹窗图片区右下角的 :Placeholder{inline hint="【图标】视频播放按钮（Icon_Marker_VideoPlay.png）"}，可在浏览器中打开视频链接。
  - 视频为点位的补充信息，并非所有的点位都有视频。

点位弹窗中，还存在以下操作：

- 当光标在点位弹窗中，且在内容区之外时，可通过鼠标滚轮，对当前点位弹窗进行放大 / 缩小操作。
- 点击点位弹窗右上角的 :Placeholder{inline hint="【图标】弹窗关闭按钮（Icon_Marker_Close.png）"}，或点击点位弹窗之外的地图区，均可关闭当前点位弹窗。

### 点位标记 {#marker-pin}

点位状态可为【未完成】或【已完成】，【未完成】表示该调查物未被获取，或未获取该调查点的物品。建议用户在确认游戏内已获取完调查点物品的情况下，再将点位标记为【已完成】。

在点位弹窗中，当前有效的状态为高亮显示。点击当前有效的状态按钮即可切换此点位状态，同时关闭点位弹窗。

## 数据更新 {#data-update}

::Placeholder{hint="【图片】截图带有数据更新提示的界面。"}

::

本软件会定时获取数据，若数据有更新，则会在地图顶部出现数据更新提示。

点击数据更新提示，则可更新数据并重新进入地图。

## 软件版本 {#app-version}

派蒙面板左下角有地图与地图插件版本显示：

- 版本号：为地图本体版本。反馈地图问题时，请带上此版本号。
- 位置追踪版本：为 :Placeholder{inline hint="【链接】位置追踪（待补链接）"} 模块的版本号。反馈位置追踪问题时，请带上此版本号。

## 离线模式 {#offline-mode}

::Placeholder{hint="【图片】带有离线模式弹窗提示的开屏界面截图。"}

::

离线模式是一种特殊的地图启动模式，用于在网络不可用时也能正常使用地图。

在未连接网络时启动地图，会弹出提示。在提示窗口中点击【进入离线模式】，即可以离线模式启动地图。

::: warning 警告

若要正常使用离线模式，在此之前请先确保至少在连接网络时启动过一次地图。否则，地图会因缺失启动所需的文件而导致启动失败。

:::

## 文本溢出显示 {#text-overflow}

::Placeholder{hint="【图片】截图包含文本溢出显示的示例，以点位弹窗+点位标题标题 tooltip 为佳。"}

::

在本软件中，当一处文本的长度超过其文本区域所能容纳的最大长度时，为了方便查看，此处文本会以一定速度往复滚动。此外，将光标移动到该文本区域时，文本的完整内容会显示在其上方。

#question
快捷开关区是否可以自定义开关功能？

#answer
不可以。快捷开关区目前开放的快捷开关为常用的功能开关。由于地图功能点较多，自定义快捷开关可能会导致小分辨率下布局占用等不可预期的 Bug。如果需要快捷开启 / 关闭某个功能，请使用 :Placeholder{inline hint="【链接】快捷键（待补链接）"} 功能。
::
