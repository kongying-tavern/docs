# Source fonts

Sarasa Gothic SC Regular, SemiBold and Bold are pinned to version 1.0.41.
SemiBold (600) and Bold (700) come from the official
[SarasaGothicSC-TTF-1.0.41.7z release](https://github.com/be5invis/Sarasa-Gothic/releases/tag/v1.0.41).
Regular (400) is the existing source from the same version.

Sarasa is licensed under the SIL Open Font License 1.1; see
[Sarasa-LICENSE.txt](./Sarasa-LICENSE.txt).
The source TTFs are committed; generated WOFF2 subsets are rebuilt locally.
